# PaperPulse

**Say it. Print it.**

PaperPulse is an open-source smart home printing
assistant that converts digital information and
voice commands into physical thermal prints.

## Project Goals

- Alexa-powered shopping list printing
- Wi-Fi-enabled thermal printing
- ESP8266-based printer controller
- Home Assistant integration
- Custom printing API
- Future mobile application

## Hardware

- ESP8266
- 58mm Thermal Printer
- USB-to-TTL converter (development)
- UART communication

## Technology Stack

- Arduino C++
- ESP8266
- Python / FastAPI
- Home Assistant
- Wi-Fi / HTTP / UART
